📖 사용 순서
준사전 등록 (관리자 1회)
  • 호기설정 — 호기번호(001…) · 호기명 등록
  • 금형설정 — 금형제번 · 품번 · 품명 · 재질/두께/폭/피치 · 비중 · 기준 SPM 등록
  • 소재입고 — 규격 선택 → LOT/HEAT NO · 입고일 · 중량 등록
기준 SPM이 없으면 설비가동이 시작되지 않습니다. 피치당 중량은 두께·폭·피치·비중으로 자동 계산됩니다.
1호기 · 금형 · 품번 선택
  • 호기 선택 → 당일 작업이 자동 시작됩니다
  • 금형 선택 시 등록된 품번이 자동 지정됩니다
  • 금형은 📷 버튼으로 QR 스캔 선택도 가능합니다
2소재 LOT 선택
  • 드롭다운에서 선택 — 현재 금형의 재질·두께·폭이 맞는 LOT만 표시
  • 📷 QR 스캔 — 소재 라벨 QR을 정사각 프레임 안에 맞춤
  • 목록에 없으면 ＋ 새 로트 등록으로 직접 입력
3🔵 설비가동
  • 버튼을 누른 순간부터 실제 가동시간이 누적됩니다
  • 가동 중에는 카운팅(ESP32)이 자동 조회됩니다
  • 가동 중 다시 누르면 대기 상태로 전환됩니다
4🟠 설비정지 (발생 시)
  • ▶ 지금부터 정지 — 사유 선택 후 실시간 카운트 시작
  • 사유 미선택 상태로 누르면 사유 선택 팝업이 뜹니다
  • ⏱ 시간 직접입력 — 시간/분 숫자판으로 사후 입력
  • 정지 중 설비가동 버튼을 누르면 즉시 정지 종료 + 시간 자동 등록
계획정지(UL-Z001/Z006/Z011)는 가동률 계산에서 제외됩니다. 정지 내역은 행별로 수정·삭제할 수 있습니다.
5🟢 소재완료 (소재 교체 시)
  • 사용 중인 코일을 다 썼을 때 누릅니다
  • 이후 다음 LOT를 선택하면 이어서 생산됩니다
6🟣 생산종료
  • 당일 작업을 모두 마쳤을 때 누릅니다
  • 이 시점의 실제 가동시간 · 가동률 · 이론수량이 고정됩니다
7📝 생산일보 작성 · 저장
  • 금형별 작업 내역이 블록으로 표시됩니다 (금형 2종이면 블록 2개 + Σ합계)
  • 블록마다 소재로트 · 정지내역이 자동 매칭됩니다
  • 각 블록에 ✅ 양품 / ❌ 불량을 숫자판으로 입력
  • 📡 카운팅은 참조용이며 수정할 수 없습니다
  • 💾 생산일보 저장으로 마감 → 작업 종료
Σ합계 블록에서 카운팅 대비 차이(정확도)를 확인하세요. 차이가 2%를 넘으면 빨간색으로 표시됩니다.
!알아두기
  • 금형을 바꾸면 작업 이력이 자동 추가되어 이전 내역도 그대로 남습니다
  • 계획 가동시간을 넘겨 작업하면 잔업으로 표시되고 가동률은 실조업 기준으로 계산됩니다
  • 연습 기록이 남았을 때는 DB설정 → 로컬 작업기록 초기화를 사용하세요
